## What this file is

dnf transaction 1 is the package set baked into the installation
image, recorded when the ISO was built rather than when this machine
was installed. Everything after it happened here — so the list below
is what a fresh install would NOT give you, and therefore what the
playbooks need to cover.

Package managers other than dnf are not represented here; see
60-flatpaks-snaps.txt, and 95-gaming-stack.txt for Proton builds,
which are unpacked tarballs that no package manager knows about.
