## What is captured here, and what is not

The settings below are an allowlist. Deliberately NOT captured,
because this file is committed to git:

  kdeconnect/                device pairing PRIVATE KEY and certificate
  kwinoutputconfig.json      monitor EDID hashes and identifiers
  kactivitymanagerd-statsrc  usage statistics (what was opened, when)
  session/, plasmanotifyrc, kconf_updaterc, Trolltech.conf,
  QtProject.conf             generated state, no settings in them

Plasma config cascades: /etc/xdg -> ~/.config/kdedefaults (the
distro's look-and-feel) -> ~/.config. The user files below therefore
already contain only what deviates from the defaults beneath them.
